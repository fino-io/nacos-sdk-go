## 前后对照

先新增回归测试并在未修改的生产代码上运行，确认问题；修复后再次使用 Go `-overlay` 加载基线版本的 7 个生产文件，以完全相同的最终测试进行对照。overlay 仅替换源码读取，不回滚工作区。

| 场景 | 修改前 | 修改后 |
|---|---|---|
| 权重 0.2 / 0.8 | 总权重取整为 0，panic | 正常选择，分布接近 20% / 80% |
| 权重 0.5 / 1.5 | 第一个实例永远选不到 | 分布接近 25% / 75% |
| 权重 1 / 3 | 正常 | 保持约 25% / 75% |
| 两个 MaxFloat64 权重 | 整数转换导致 panic | 按最大权重归一化，约 50% / 50% |
| 正无穷权重 | panic | 排除无效实例；无可用实例时返回错误 |
| 零、负数、NaN、负无穷权重 | 被排除 | 保持排除 |
| 非健康、禁用实例 | 被排除 | 保持排除 |
| 删除已有空/全空白快照 | 删除后重新创建文件 | 文件保持不存在 |
| 删除不存在的快照 | 成功 | 保持幂等成功 |
| 删除非空目录失败 | 错误被吞掉 | 返回错误 |
| 配置写入失败 | 错误包含完整配置 | 不再包含配置正文 |
| 普通配置写入、覆盖、保留空白与中文 | 正常 | 保持逐字节内容 |
| HTTP 200 | 返回正文、关闭响应体 | 保持原行为 |
| HTTP 403 / 500 | 响应体未关闭 | 返回空结果并关闭响应体 |
| 不支持的 HTTP method | nil 指针 panic | 返回空结果/错误 |
| 响应体读取失败 | 返回空结果、关闭响应体 | 保持原行为 |
| GET 特殊字符参数名 | 参数名被拆分 | 正确编码键和值 |
| DELETE 已有 query | 二次追加问号，破坏原 query | 保留原 query 并追加参数 |
| PUT 特殊字符及空值 | 未编码，空值丢失 | 使用标准表单编码，保留空值 |
| POST 特殊字符及空值 | 正常 | 保持原行为 |
| 非法 URL、请求超时 | 返回错误 | 保持原行为 |

权重分布每组采样 10,000 次，容差为绝对比例 0.04；这是概率回归检查，不要求随机序列与旧版本一致。超大权重先缩放，防止求和溢出。极小权重相对极大权重仍受 float64 精度限制。

## 兼容性影响

- 公共方法签名和依赖保持不变。权重选择的随机序列和排序过程改变，但正常整数权重的概率语义保持一致；小数权重现在按实际值参与选择。
- 快照沿用“空或全空白表示删除”的既有约定；删除后直接读取普通配置返回文件不存在错误，不再读取到重新创建的空文件。已有测试已更新相应断言。
- PUT 现在传递空字符串参数，供调用方明确清空字段；此前会直接遗漏。GET/DELETE 保留已有 query 参数，追加值使用标准 URL 编码。
- HTTP 错误日志不再打印传入的完整 header 和 params；配置写入错误不再打印正文。URL 和底层错误仍保留用于诊断，调用方不应把秘密放在 URL 中。
- TLS 默认校验、缓存原子写入、订阅、鉴权、重连逻辑未在本轮调整。
